## About Laravel
Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

This project is a task management system built with Laravel and PHP, using MySQL as the database (managed via phpMyAdmin). 
For the user interface, the Filament admin panel was used to provide a modern and efficient UI experience.

The application implements a complete authentication system, session handling, and image processing functionality. 
It allows users to create and manage tasks within a structured and role-based system.

The platform includes an admin panel where administrators can manage task categories, perform full CRUD operations on tasks, and assign tasks to specific users.

For end users, the application provides a dashboard and a dedicated tasks page where they can view their assigned tasks and create new ones. Users also have access to a profile section where they can change the interface theme and log out of the system.

### Main Features
- Laravel-based architecture with MySQL database
- Authentication and session management
- Filament admin panel integration
- Image upload and processing
- Task management system (CRUD operations)
- Task categories management
- Task assignment to users
- Admin dashboard with full control
- User dashboard and task overview
- Theme customization for users
- Profile management and logout functionality
